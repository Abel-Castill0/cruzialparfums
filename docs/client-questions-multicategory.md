# Cruzial Import: relojes y otros productos — 7 decisiones

Para preparar Import para relojes y otros productos de alta gama necesitamos siete decisiones suyas. Cada una trae lo que haremos
**si no responden**, para que el trabajo no se detenga. Si prefieren otra cosa, basta con decírnoslo.

## 1. Qué categorías vendrán y cuándo

| # | Pregunta | Si no responden, hacemos esto |
|---|---|---|
| 1 | **¿Qué productos se suman y para qué consolidado?** (relojes, joyería, bolsos, accesorios…) | **Relojes primero.** Dejamos la tienda lista para sumar otras categorías después, sin rediseñar. |
| 2 | **¿Cada consolidado será de una sola categoría o mezclará varias?** | **Se puede mezclar.** La portada habla de «productos importados» y muestra las categorías como puertas de entrada. |
| 3 | **¿Las piezas de mayor precio se piden como hoy (añadir y confirmar por WhatsApp) o se consultan antes? ¿Piden anticipo?** | **Todo sigue como hoy.** Dejamos listo un botón «Consultar por WhatsApp» que se activa a partir de un monto que ustedes elijan. |

## 2. Cómo se presentarán

| # | Pregunta | Si no responden, hacemos esto |
|---|---|---|
| 4 | **¿Qué fotos habrá de cada producto?** (fondo blanco, recorte, fondo oscuro, en la muñeca) | Pedimos **1 foto principal limpia y 1 de detalle**, y mostramos cada foto tal cual, sin retoques. |
| 5 | **¿Qué datos de cada producto se muestran y cuáles son obligatorios?** (en un reloj: tamaño de caja, material, mecanismo, correa) | **Lista básica obligatoria** (marca, modelo, tamaño, material) y datos opcionales por categoría, que completamos con ustedes antes de abrir. |
| 6 | **¿Qué garantías y pruebas de autenticidad pueden prometer?** (certificado, garantía oficial o del importador, envío asegurado) | **No mostramos ninguna promesa nueva.** Sólo publicamos lo que confirmen por escrito. |

## 3. Cómo se filtrarán

| # | Pregunta | Si no responden, hacemos esto |
|---|---|---|
| 7 | **¿Qué filtros quieren?** Comunes a todo (marca, precio, disponibilidad) y propios de cada categoría (en relojes: tamaño, material, mecanismo). | **Filtros comunes siempre** y **hasta 3 propios por categoría**, tomados de los datos obligatorios de la pregunta 5. |

## Lo que damos por hecho

- El nombre **Cruzial Import** y su azul se mantienen. La venta se cierra por WhatsApp, como hoy.
- Import **no** tendrá el recomendador de fragancias; si hace falta una guía para elegir, será distinta para cada categoría.

**Necesitamos respuesta a las preguntas 1, 3 y 6 antes de diseñar;** el resto avanza con lo propuesto.
