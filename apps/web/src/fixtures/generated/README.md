# Generated legacy fixture

`legacy-catalog.json` is generated from the repository-root `assets/data.js` by
`scripts/export-legacy-catalog.mjs`. Do not edit the JSON by hand.

This fixture exists only for legacy visual/functional parity. It carries source
provenance, a checksum, and legacy verification metadata. It is explicitly ineligible
as an automatic Supabase seed or as verified commercial data.
